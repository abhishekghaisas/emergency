No signal? Satellite mode
  1. Go outside with a clear view of the sky and horizon.
  2. In an emergency, try Call 911 first. With no coverage, iPhone offers Emergency SOS via satellite. Follow its prompts. Don’t use Messages for emergencies.
  3. To reach family, tap Prepare satellite alerts. Satellite can’t send group messages, so you send one message per person.
  4. When Messages offers to connect to a satellite, tap it and point your phone as shown.
  5. Each message can take 30 seconds or more. Wait for each to send before the next.

Needs iPhone 14 or later and iMessage turned on before you lose coverage. Try the practice mode in Settings, Apps, Messages, Satellite Connection Demo.

Set up contacts and details

One person per line: a name, then the number with country code. Put them in the order you want to call. Saved only on this device.

911 script

Read the script to the dispatcher. If you can’t speak, text 911 and paste the short version. Text-to-911 isn’t available everywhere, and calling is better when you can.

Install on iPhone and Mac

iPhone: open this page in Safari, tap Share, then Add to Home Screen. Mac: in Safari, choose File, then Add to Dock.

This page can’t make calls or send texts on its own. It opens Messages and Phone with everything filled in, and you press send. Cell service is required.

Not a replacement for 911. If you’re in danger, call 911 first when it’s safe to do so.
